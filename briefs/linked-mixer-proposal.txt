Implementation supersedes the original optional-transfer proposal.

See docs/linked-mixer.md for the current UI, startup election, framing,
bandwidth limits, recovery and timing contract. In particular there is no
live optional-transfer admission window: metadata uses spare bits of the
existing numbered clocks and existing full-duplex reply bytes. It adds zero
serial transfers during playback. Names update automatically after successful
save/load/song load; only layout persistence waits until stopped.
