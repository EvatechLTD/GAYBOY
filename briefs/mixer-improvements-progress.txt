Implemented
-----------
Boot selects native GAYBOY / AUTO. The native ROLE selector offers AUTO,
MASTER and SLAVE; other sync formats retain manual roles. AUTO peers listen
while stopped, a local start claims master, and an incoming start retains
slave. A master stop returns AUTO peers to listening. Selected policy and
active role are separate. A locally stopped slave remembers the peer's
running transport and cannot steal clock ownership on local restart.
An already listening slave is not rearmed by foreground stop handling,
which could otherwise restart an in-flight external serial transfer.

SELECT on Mixer opens a visibility checklist for seven main tracks,
13 drum voices and eight pads. A hides/shows; B restores all; SELECT closes.
Visible tracks compact horizontally. Hidden pads use a compact labeled
grid with original slot numbers and active/queued markers. Hidden active
pads are called out. Navigation skips hidden items and an empty layout
returns focus to the header. Hiding never changes audio or pattern data.
Visibility currently lasts for the session, including page changes.
The layout renderer lives in bank 60; bank 18 could not fit all new UI.

Not implemented / not claimed
-----------------------------
No handshake, name requests, background polls, extra serial transfers,
remote control protocol, remote mirror, linked mixer strips, reorder or
layout persistence is implemented in this checkpoint. No new serial ISR or
oscillator instructions have been added. Live optional traffic must remain
disabled until admission safety and instrument-level CPU/timing parity are
demonstrated. Piggyback replies still require measured CPU work.

Near-simultaneous AUTO starts/collision arbitration and physical hardware
verification remain outstanding. AUTO is not ready to promise collision
recovery. Forced roles remain available. Do not publish this as a completed
linked-mixer release or claim full timing parity from these initial tests.
