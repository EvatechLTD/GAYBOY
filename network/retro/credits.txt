Y2KCRISIS retro music player dependencies

Cowbell (Matt Westcott and contributors), BSD-3-Clause:
https://github.com/demozoo/cowbell
Builds: https://demozoo.github.io/cowbell/cowbell/
Files: cowbell.min.js, openmpt.min.js, libopenmpt.js, libopenmpt.wasm.
cowbell-audio.js is its WebAudio wrapper adapted to add a volume gain node.

libopenmpt (OpenMPT contributors), BSD-3-Clause and bundled component notices:
https://lib.openmpt.org/ - see openmpt-LICENSE.txt.

jsSID 0.9.1 (Mihaly Horvath / Hermit), adapted for Cowbell by Gasman:
https://github.com/og2t/jsSID - see jssid-README.txt for license and limitations.
https://github.com/demozoo/cowbell/blob/main/cowbell/jssid.js
The unminified SID source retains the original author credit.

JZZ 1.9.6, JZZ-midi-SMF 1.9.9, JZZ-synth-Tiny 1.4.4 (Jazz-Soft), MIT:
https://github.com/jazz-soft/JZZ
https://github.com/jazz-soft/JZZ-midi-SMF
https://github.com/jazz-soft/JZZ-synth-Tiny
Exact npm package versions are vendored; see the matching LICENSE files.
Tiny Synth implements General MIDI using Web Audio synthesis, not a soundfont.

No remote decoder scripts, tracking, or music catalog requests are required.
All engines are loaded on first playback. File URLs hosted elsewhere need CORS.
SID support has jsSID's limitations (including no digital samples).

The Cowbell OpenMPT adapter now rejects decoder initialization failure.
jsSID allows zero background noise in its options.
