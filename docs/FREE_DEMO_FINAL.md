# Final free demo

This public main and the `free-demo-final` tag preserve the final free demo.
The public browser emulator and downloads remain on this build.

- Engine source: ddad9ea7c4ce1d56915698e7eef1ff580cc1fae9.
- ROM: GAYBOY.gb, 1 MiB MBC5 with 32 KiB battery SRAM.
- ROM SHA256: adf25cd8612d51cbc12b15e040f9c37edb5a2aaad4d5e3c819493d8a1c65f98e.
- Bundled project: assets/demo/KILLING.srm.
- Demo SRAM SHA256: 4e5726633cdaa689b39eb4ced4f7b5255cd07c2d48d1506cfff5f5715a5077c8.

The release supplies the ROM, a matching standalone demo SRAM file and checksums.
Use a separate filename for the demo when preserving your own compositions.
Five resident patterns and one song occupy the existing 32 KiB save layout.

The freeze commit changes documentation only; its engine and public ROM are
unchanged. Future development is not published in this repository or through
its existing emulator/download endpoints.
