Hardware test

Use the named ROM in build/hardware. A fresh save initializes normally; this
package contains no replacement battery save. Existing settings retain their
clock selection.

From a sequencer track: hold Start, choose Edit > Generate, release Start.
Up/down selects a field; hold A or B with arrows to edit. APPLY accepts the live
preview; Select or CANCEL restores entry notes. Preview uses the copy clipboard.
On DRUM, the highlighted drum voice alone is regenerated. For held triads, choose
Role CHORD, then enable the instrument's existing ARP mode to cycle its notes.
