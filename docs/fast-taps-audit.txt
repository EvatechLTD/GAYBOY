Fast tap release prototype (2026-10-23), branch black-notes, unmerged.
Baseline: frozen GAYBOY-selection-gesture-test.gb.
Candidate: GAYBOY-fast-taps-test.gb, separate copied save, no deployment.

Input no longer runs the single-note release replacement. It queues release
and foreground rendering services it after queued edges drain. Several taps
can coalesce before service. A new queued input after erase interrupts before
insert; native dirty-span composition repairs any partial replacement.
Drum single-note replacement also moves outside the input handler.
Multi-note native redraw retains the existing bounded compositor, reduced
from eight to four events per scanning batch; tile upload batches remain two.
Small completed stages fall through so painting retains its fast feedback.

Group membership uses a 32-byte bitset. Cache count once, use local selection
comparisons, and read/write selected events only after validation. Reuse
membership for repeated group moves when slot,track,count,generation and
selection box still match. Bounds and horizontal collision checks remain.
Resize invalidates this cache before using its bitmap workspace. Added 48
bytes of state across the changes; spare WRAM now285 bytes plus512 stack.
The source-data edits still happen during input; offset-only transactions
are not implemented. First scans and horizontal collision scans can be slow.
