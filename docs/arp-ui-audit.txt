Changes
- Menu and instrument/modulation pages use the existing changed-span map uploader.
- Map uploads yield between rows when input is queued, except hidden transitions.
- Foreground sequencer catch-up yields after a slice when input is queued on any page.
- Shorten the native timer countdown, retain exact elapsed/deadline/wrap behavior.
- Compute DIV fractional elapsed time with byte arithmetic instead of word shifts.
- Split heavy fallback wait/attack frames out of idle/native foreground polling.
- Skip inactive arp scans and impossible native preparation for random orders.
- Normal native phase wrap subtracts once; large catch-up retains remainder fallback.
- Retain continuous native packets across unrelated edit generations after checking
  their actual rate, instrument, mixer level and sequence length.
- This last check fixes late redundant foreground retriggers at loop boundaries.
- Current limits remain straight/dotted 1/32, triplet 1/16, free 1..16 Hz, BPM<=240.

Measurement
- DMG PyBoy with the preserved four-note P2 ARPTEST, Wave and original drums.
- Baseline: build/GAYBOY-arp-limits.gb; identical capped settings and saved pattern.
- Saved AUTO/link-master configuration uses 1024 timer interrupts/sec with no peer.
- Internal-clock run explicitly disables link sync and uses the ordinary 256 Hz timer.
- Input acknowledgment measures sampled edge to lastpad consumption, not finished drawing.
- Timed entry/return hooks use emulated CPU cycles, not host execution time.
- Inclusive function spans overlap. Timer percentages below are the measured handler
  body including its callees, not total CPU utilization or all arp-related work.
- The foreground busy-loop uses remaining cycles; screen-scan percentages include
  repeated comparison work and are not equivalent to the cost of drawing one frame.

Limits
- Dense chord dragging and selection remain costly, especially at 240 BPM.
- Some edit inputs still exceed the six-second test bound; successful final edit
  application does not mean all intermediate inputs were timely.
- Random/modulated fallback arps remain much more expensive than native packets.
- Source changes do not remove logical phase maintenance entirely; it remains
  necessary for fallback/ownership handoffs and retained-phase transport.
- WRAM headroom 1154 ->1127 bytes (27 bytes for packet-input validation); stack512 unchanged.
- Emulator evidence requires hardware validation. No merge, commit or push.
