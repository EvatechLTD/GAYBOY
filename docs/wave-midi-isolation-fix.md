# Internal notes accidentally launching MIDI pads - 2026-10-23

Hardware report: Wave C1 was silent while C2 sounded. Plotting/editing low
Wave notes on pad 1 could also switch to pad 5 or interrupt playback.

Cause: `event()` handled both internal musical events and decoded external
MIDI, and called `mixer_midi()` before instrument routing. MIDI notes 24-28
(C1-E1) were therefore consumed as pad 1-5 performance commands even when
generated by playback, ARP, audition or editing. The released ROM reproduced
an unintended queued pad launch during C1 playback. Existing MIDI tests
covered incoming mappings but did not establish isolation from internal notes.

Fix: only the external byte parser calls the new `midi_event()` entry point,
which applies MIDI performance mappings before normal instrument dispatch.
Internal callers keep using `event()` and cannot enter the performance mapper.

MIDI pad launching now defaults OFF at boot. SYNC has a third selectable row,
MIDI LAUNCH. Tap A/B to toggle; A/B plus Up/Right enables, Down/Left disables.
It is a session setting, like sync type/role. Changing it leaves transport and
sync configuration intact. Disabling cancels a matching pending MIDI launch,
clears MIDI held-key state, and prevents stale retriggering after re-enabling.
External fader/mute CC mappings remain independent. Disabled launch notes use
normal external instrument routing instead.

Validation:

- 24 audio checks: C1, C#1, D1, D#1, E1 and C2, with launch ON/OFF and MOD
  bypass ON/OFF. Correct audio pitch, sustained Wave output, no pad changes
  and no queued launches. C1 measured about 32.85 Hz, C2 about 65.20 Hz.
- Actual B plotting/resizing of C1-E1 over 16th-note synth hi-hats, followed
  by repeated loops, with MIDI launch ON and OFF. No transport interruption,
  pad change or call to the pad-launch entry point.
- Serial RX tests: default OFF, disabled note routing, actual SYNC menu toggle,
  all five external pad launches, held quantized retrigger, note-off and CC123,
  live disable cleanup and re-enable without reviving stale held keys.
- External MIDI level/mute/launch coexistence with active edit snapshots.
- Sustained Wave publication, overlapping note admission, ARP/top-bar flow
  and deferred painting regression checks passed.
- ROM layout: 1 MiB MBC5, 32 KiB cartridge RAM, 283 bytes spare WRAM below
  audio tables and 512 bytes reserved stack. One new byte of session state.
