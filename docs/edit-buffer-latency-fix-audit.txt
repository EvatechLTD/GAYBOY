Changes:
- Prepare up to16 snapshot events per main-loop pass instead of one.
  Service audio between records and yield for queued input. Abandon work
  if an audio-service pattern launch changes resident slot/generation.
- Publish a ready snapshot in the native IRQ before step0 when the longest
  populated track is owned by that dispatcher. Foreground publication
  remains for other tracks/modes; chord/drum invalidation stays foreground.
  Do not swap during foreground sequencer servicing.
- Refresh native LFO pitch atomically at foreground pulse/Wave attacks.
  A stale precomputed pitch could otherwise overwrite a newer IRQ phase;
  changed scheduling exposed this preexisting race in the LFO regression.
