Implementation
- Cache chord note ranks/frequencies and rate quotient/remainders.
- Compile common ordered chords (up to four notes) into native APU packets.
- A small timer countdown drives attacks; packet work runs only at a deadline.
- Packet updates are staged and published atomically after foreground catch-up.
- Preserve logical foreground phase while the timer owns audible attacks.
- Handle musical loop retriggering in the timer; retain free phase when disabled.
- Keep unchanged packets playing during unrelated edits and across UI pages.
- Respect shared P1/Wave ownership, zero mixer level, mute/solo and transport.
- Retain generic synthesis for random orders, larger chords, pitch/modulation,
  ADSR, tables, swing and externally clocked slave playback.
- Use the existing DIV time accounting through native/PCM timer changes.
- Skip arp preparation and timer calls when arps are inactive.

Limits and interpretation
- This is an emulator-tested prototype, not a hardware-qualified release.
- 172 measured conditions include overload cases; they are not 172 usability passes.
- 240 BPM at the fastest divisions and 2-4 ms freerun can still starve input.
- A missing acknowledgment means no response within the six-second test bound.
- Dense chord dragging remains slow to draw even while its arp stays regular.
- Freerun with RETRIGGER ON intentionally shortens some intervals at bar reset;
  the retained-phase matrix separates this behavior from timing jitter.
- Arp/LFO ranges remain unchanged. The earlier 240 BPM cap remains in place.
- Native fast mode currently covers deterministic orders and ordinary native
  voices. LFO/ADSR/pitch-modulated, random and larger-chord arps still fall back.
- LFO algorithm/limits are unchanged; 1836 phase/clock comparisons match baseline.
- No-arp navigation median/max input acknowledgments remain about 33.5/83.7 ms.
  Matched navigation gesture duration was 3.48 s before vs 3.78 s after;
  idle timing remains below 1 ms in that separate fixture.
- WRAM headroom: 1736 -> 1154 bytes; 512-byte reserved stack unchanged.
