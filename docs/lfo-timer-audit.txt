UI regression follow-up, 2026-10-22

User confirmed1/32 became usable, but navigation and editing regressed.

Replaced Q12 period multiplication/octave shifting in IRQ with the existing
fixed-ROM MIDI-note frequency lookup. Foreground prepares signed semitone and
fine offsets; table is384 bytes instead of768. Pitch kernel uses register ABI
assembly; checked518,784 combinations of channel,note,coarse and fine bounds.
This follows the ROM note table's rounding, which can differ from the previous
period-scaling approximation by hardware frequency ticks (e.g.1547 vs1548).
Clamps to supported note table and0..2047 frequency range.

spills. Timer sequencer phase dispatcher now keeps accumulation in registers.
