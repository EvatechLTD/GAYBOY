CLEANUP PASS 1 - 2026-10-22
Branch: cleanup; baseline: main 365891f

Changes
- Removed 32 retired sequencer no-op/constant-return entry points, their banked
  calls, unreachable native-launch branches, write-only launch flags/counters
  and the redundant input interrupt wrapper.
- Removed unused Wave2 settings, modulation tables, UI label pointers, preset
  field, empty wrappers and its unreferenced 4096-byte gain lookup header.
- Removed write-only poly ownership/sustain fields and unused retired DSP
  envelope, release, amplitude-map and diagnostic state.
- Preserved live tone invalidation, buffered IRQ cancellation/PCM accounting,
  active MS sequencing, shared serial HRAM, pulse suppression and drum envelopes.
- Cable tests accept a baseline ROM argument and drive the current MONOSIMP
  held-Start page menu while retaining support for the earlier receiver UI.

Memory and ROM
WRAM headroom below fixed audio tables: 1607 -> 1736 bytes (+129).
Stack reserve remains 512 bytes. Banked code/data: 491660 -> 486797 (-4863).
Fixed ROM end: 0x2dc4 -> 0x2d90 (52 bytes recovered). ROM stays 1 MiB.

Timing remains tight, with slightly higher maxima in some phases. This is
a code/memory cleanup, not a demonstrated reduction in audio jitter. Input
response changes are mixed; no uniform editing-speed improvement is claimed.
Native paint duration improves about 2%; the PCM paint fixture avoids its
baseline input-latency outlier. Native selected-note movement takes about 2%
longer overall despite a lower median acknowledgement delay.

Remaining audit areas
- Remaining legacy mono/poly mode gates and experimental exp_* wrappers need
  a separate reachability review; shared waveform and ownership code still
  has real callers. Do not remove solely on old names.
- Fixed-address pulse IRQ flags overlap native serial storage. This pass does
  not reclaim or reinterpret those addresses.
- Historical DSP/Mono tests target retired features; active regressions still
  reuse some fixture helpers. Do not delete all historical tools blindly.
- Track-number compaction and pattern-format changes were not part of this pass.

Limits

The current companion passes reconnect even with baseline GAYBOY; that result
is not attributed to this cleanup. The prior bug report records another ROM.
