How 2 make some noise

  1. Grab the .gb file.The big ridiculous button above is your friend.
  2. Load it in your Game Boy emulator.Map the D-pad, A, B, Start and Select. Press Start to skip the intro and open the menu.
  3. Find your sound.Choose an instrument or the sequencer from the Start menu. Experiment. Save a pattern when you like it.
♥ A note for the MIDI nerds: External MIDI uses Arduinoboy in mGB mode. Seven logical tracks share the Game Boy’s four physical sound channels. Pattern saves need battery SRAM support and don’t recall every synth setting yet.
